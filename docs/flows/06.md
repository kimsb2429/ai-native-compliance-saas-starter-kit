# flow 06 · A3 · new agent row gap checker

## What you send

I sent a request from the Acme Fabrication tenant using the payload file `examples/payloads/06-new-agent-row-gap-checker.json`.

```json
{
  "agent_ref": "gap-checker",
  "prompt": "Which three of our obligations matter most to regulators, and what record proves each one was done?",
  "stream": false
}
```

## What runs

1. scripts/demo.py runs db/flows/06-insert-gap-checker.sql as the owner role: one INSERT into agent_definitions adds gap-checker (model_size medium, prompt slug gap-checker-system, tools [list_obligations]); the prompt slug was seeded already
2. acme-user invokes agent_ref gap-checker in a new session with the question about which obligations matter most to regulators and what record proves each
3. agent/builder.py finds the new row, resolves its prompt, binds list_obligations to Acme, and builds the agent from the same container image that served every earlier flow

## What comes back

The system returned a ranked list of three regulatory obligations with supporting records.

```json
{
  "agent_ref": "gap-checker",
  "agent_version": 1,
  "prompt_slug": "gap-checker-system",
  "prompt_revision": 1,
  "model_id": "us.amazon.nova-pro-v1:0",
  "tools_used": [
    "list_obligations"
  ],
  "stop_reason": "end_turn",
  "text": "1. **[Air Quality Operating Permit AQ-2024-0117 §5.1]** Notify the Department by telephone within 24 hours of any malfunction that causes emissions to exceed a limit in Section 1, and in writing within 7 days. — **Record:** Notification log and written report.\n2. **[Air Quality Operating Permit AQ-2024-0117 §4.1]** Submit an annual emissions inventory report to the Department by March 1 of each year, covering the previous calendar year. — **Record:** Annual emissions inventory report.\n3. **[Air Quality Operating Permit AQ-2024-0117 §4.2]** Submit a semi-annual monitoring report by July 31 and January 31, summarizing all deviations from permit conditions. — **Record:** Semi-annual monitoring report.",
  "elapsed_ms": 4255
}
```

The response confirms the agent used the correct tenant context and tool. The agent_ref and prompt_slug values match the inserted row. The model accessed only Acme's data through list_obligations, proving RLS enforcement and tool binding at build time.

## What it proves

This flow proves the A3 spine decision: agents are database rows. One INSERT into agent_definitions adds a fully functional agent without redeploying the runtime. The container image remains unchanged across flows. The new agent uses the same code path as prior agents, built dynamically from the row.
