# flow 04 · A26 · prompt revision then ask

## What you send

I sent the request as the tenant Acme Fabrication using the payload file 04-prompt-revision-then-ask.json.

```json
{
  "agent_ref": "compliance-assistant",
  "prompt": "What do we have to do every quarter under our air permit?",
  "stream": false
}
```

## What runs

1. scripts/demo.py runs db/flows/04-activate-revision-2.sql against the database as the owner role: it inserts revision 2 of compliance-assistant-system (a checklist-only format, model MODEL_MEDIUM) and flips is_active from revision 1 to revision 2
2. the same payload as flow 02, one question, is sent as acme-user in a new session; a new session is a new microVM, so the 60 s prompt cache is cold and the registry read returns revision 2
3. the answer comes back in the checklist format and the response carries prompt_revision: 2; the container image and the runtime were not touched
4. scripts/demo.py runs db/flows/04-restore-revision-1.sql so the seed state is restored

## What comes back

The system returned a checklist-formatted answer under the active prompt revision 2.

```json
{
  "agent_ref": "compliance-assistant",
  "agent_version": 1,
  "prompt_slug": "compliance-assistant-system",
  "prompt_revision": 2,
  "model_id": "us.amazon.nova-pro-v1:0",
  "tools_used": [
    "list_obligations"
  ],
  "stop_reason": "end_turn",
  "text": "1. [Air Quality Operating Permit AQ-2024-0117 §2.1] | quarterly | Conduct a performance (stack) test on Stack S-1 once every calendar quarter, using EPA Method 5, and submit results within 30 days of the test.",
  "elapsed_ms": 3253
}
```

The prompt_revision field is 2, confirming the newer prompt version was used. The text is formatted as a numbered checklist, which matches the structure defined in revision 2. The tools_used field shows list_obligations was called, indicating the agent still retrieves data correctly under the new prompt.

## What it proves

This flow proves that changing the active revision in the prompt registry updates agent behavior without requiring a redeploy. The response includes the prompt revision number, enabling traceability. The system uses the updated prompt format while maintaining correct tool integration and tenant isolation.
